# betaservis

Каркас для сайта сервисного центра по обслуживанию ноутбуков, компьютеров и другой оргтехники.
Для услуг по разработке, тестированию.


*******
Проект каркас на Django 5.1.6, Python 3.11


*******
Основные возможности:

1. По части фронтенда интегрирован шаблон Bootstrap. используется Jinja.
2. Основное меню верхнего расположения, основная информация выводится ниже фоновой картинки с важными блоками.
3. На начальной странице будут открываться новости, несколько блоков. и ссылка переход на страницу всех новостей (пока
   этот блок в разработке).
4. Вывод из меню осуществляется так же внизу фоновой картинки( это реализовано и на этапе тестирования).
5. По части бэкенда используется иерархическое меню созданное с помощью django-mptt, категории являются ссылками
   верхнего меню.
   а содержимое выводимое на страницы это материалы в категории.
6. В дальнейшем планируется добавить приложение "Каталог" для продажи комплектующих для компьютера.
7. Регистрацию и аунтификацию пользователя.
8. Форму для отправки собщений.
9. Систему Api методов для модуля "Каталог"
10. Автотесты для Api методов. системы авторизации.

*******
На данном этапе База данных проекта - SQLite, по мере увеличения проекта планирутся переход на PostgreSQL

*******
Для запуска проекта локально:
Склонировать проект.
Создать виртуальное окружение.
Установить зависимости из файла requirements.txt.
Запустить миграции.
Запустить проект, используя команду python manage.py runserver.

*******
На данный момент проект разрабатывается локально и развернут для тестирования на сервере http://45.67.32.32/
используется "Makeclode".
В дальнейшем на сервере планирутся использовать Docker.  в первую очередь для базы. затем уже протетировать сам проект.
